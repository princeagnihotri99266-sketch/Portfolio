PROJECT ARCHITECTURE & METHODOLOGY

AI-Based Voice-Controlled Automated Troubleshooting & Lab Assistant

Developed for Computer Hardware & Networking Maintenance (CHNM) laboratories at NSTI Kanpur, this hands-free assistant allows trainees to diagnose hardware and network faults verbally while keeping both hands free for physical inspection and multimeter/cable checks.

System Architecture Flow

1. Microphone Audio Capture
→
2. Speech-to-Text (STT)
→
3. Python Orchestrator & Read-Only OS Checks
→
4. Safety-First LLM Prompt
→
5. Text-to-Speech (TTS) Speaker Output

End-to-End 7-Step Diagnostic Workflow

  1. Voice Symptom Capture: Trainee describes the hardware or network symptom via microphone.
  2. Speech-to-Text Transcription: STT library converts spoken fault descriptions into structured text queries.
  3. Initial Safety & Power Verification: Assistant confirms physical safety precautions, power supply status, and cable seating before deeper checks.
  4. Read-Only OS & Network Diagnostics: Python triggers non-destructive OS utilities (such as IP configuration and Ping reachability checks) to gather live state data.
  5. AI Fault Reasoning (Safety-First Prompt): The LLM evaluates symptoms and diagnostic outputs under strict safety guardrails—prohibiting registry edits, disk formatting, or destructive commands.
  6. Guided Step-by-Step Resolution: The Text-to-Speech (TTS) engine reads clear, incremental troubleshooting actions through the speaker.
  7. Verification & Lab Documentation: Confirms fault resolution and logs the standardized CHNM lab fault-diagnosis sequence.
